# Kazakhstan Travel Website

## Project Overview

**Kazakhstan Travel** is a responsive travel website created to demonstrate modern HTML, CSS, CSS Media Queries, and Bootstrap techniques.

The project focuses on responsive design, Bootstrap components, layout systems, navigation, forms, accessibility, and reusable UI elements.

## Technologies Used

* HTML5
* CSS3
* CSS Media Queries
* Bootstrap 5
* JavaScript
* Responsive Web Design

## Implemented Tasks

### Task 1 – Responsive Typography

Responsive typography was implemented using CSS Media Queries.

* Mobile devices use smaller font sizes.
* Tablet devices use medium font sizes.
* Desktop devices use larger font sizes.

The typography automatically changes according to the viewport width.

### Task 2 – Responsive Card Group

A group of three cards was created using custom CSS and Media Queries without Bootstrap.

Responsive behavior:

* **Desktop:** 3 cards in one row.
* **Tablet:** 2 cards in the first row and 1 card in the second row.
* **Mobile:** 1 card per row.

### Task 3 – Bootstrap Grid Layout

Bootstrap Grid was used to create responsive page layouts.

Implemented examples include:

* `container`
* `container-fluid`
* `row`
* `col-sm-*`
* `col-md-*`
* `col-lg-6`
* `col-lg-4`

The project contains sections with both two-column and three-column layouts.

### Task 4 – Bootstrap Spacing Utilities

Bootstrap spacing utilities were used instead of unnecessary custom margin and padding rules.

Examples:

```html
mt-lg-4
px-sm-2
p-3
m-3
gap-3
```

These utilities help maintain consistent spacing and responsive layouts.

### Task 5 – Bootstrap Navigation Bar

A responsive Bootstrap navigation bar was added to the website.

The navigation contains links such as:

* Home
* About Us
* Destinations
* Tours
* Categories
* Contact

The navigation collapses into a hamburger menu on smaller screens using Bootstrap's navbar collapse functionality.

### Task 6 – Bootstrap Buttons

Bootstrap button components were used throughout the website.

Implemented classes include:

```text
btn
btn-primary
btn-secondary
btn-outline-*
btn-sm
btn-lg
btn-group
```

Related actions are grouped using `btn-group`.

### Task 7 – Bootstrap Carousel

A responsive Bootstrap Carousel was implemented.

The carousel contains:

* 9 images
* Slide indicators
* Previous button
* Next button
* Responsive layout

The carousel is integrated into the Bootstrap grid.

### Task 8 – Bootstrap Cards

At least three Bootstrap cards were created.

Each card contains:

* An image
* A title
* A description
* Appropriate Bootstrap card classes

The cards are placed inside a responsive Bootstrap grid.

### Task 9 – Responsive Form Design

The website contains a responsive form using Bootstrap form components.

Implemented components include:

```text
form-control
form-select
input-group
form-check
checkbox
radio buttons
```

The form adapts to different screen sizes.

### Task 10 – Accessibility

Accessibility improvements were implemented throughout the website.

The project uses semantic HTML elements such as:

```html
<nav>
<main>
<section>
<article>
<button>
<form>
```

Images contain meaningful `alt` attributes where appropriate.

Interactive elements use appropriate labels and ARIA attributes when required.

The website also considers text and background contrast to improve readability.

## Responsive Design

The website was tested for three major screen sizes:

| Device  | Layout                       |
| ------- | ---------------------------- |
| Mobile  | Single-column layout         |
| Tablet  | Two-column / adaptive layout |
| Desktop | Multi-column layout          |

CSS Media Queries and Bootstrap responsive classes are used together to provide adaptive layouts.

## How to Run the Project

### Option 1 – Open Locally

1. Download or clone the project.
2. Extract the ZIP archive.
3. Open the project folder.
4. Open `index.html` in a web browser.

### Option 2 – Use VS Code

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Open `index.html`.
4. Click **Open with Live Server**.
5. The website will open in your browser.

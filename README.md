# Kazakhstan Travel

Multi-page travel website about Kazakhstan (HTML, CSS, Bootstrap 5, JavaScript).

## Assignment 5 - Advanced JavaScript and DOM Manipulation

| Feature | File |
|---|---|
| Day / Night theme switch | `js/theme.js`, `css/style.css` |
| Sound effects + mute button | `js/sounds.js`, `sounds/` |
| Arrow-key menu navigation | `js/nav.js` |
| Time-of-day greeting (switch), random fact | `js/home.js` |
| Learn More / Show Less | `js/culture.js` |
| Tour objects, filters (switch), Load more, star rating | `js/tours.js` |
| Multi-step registration form (callbacks) | `js/multistep.js`, `js/validation.js` |
